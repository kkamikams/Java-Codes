This repository contains a variety of Java codes that I am working on as part of my learning journey. I will be experimenting with concepts such as variables, operators, loops, conditionals, classes, and eventually more advanced object-oriented programming principles.

I built this repository not just as storage but as a record of my development. It allows me to track how my coding style and problem-solving skills change over time. This repository allows me to clearly see my own progress and recognize areas where I need more practice.
